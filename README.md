# Typoluck

**Wortspiele mit Freunden.** Das erste Spiel ist Wordle auf Deutsch: jeden
Tag ein neues Wort mit fünf Buchstaben, sechs Versuche. Das Tageswort ist für
alle gleich — wer löst es am schnellsten?

**Spielen:** https://up-birdo.github.io/Typoluck/

## Was es kann

- **Tageswort** — einmal am Tag, zählt für die Rangliste.
- **Übung** — Zufallswörter, so oft du willst.
- **Rangliste** — heute oder die letzten 7 Tage, alle oder nur deine Freunde.
- **Freunde** — suchen, anfragen, annehmen.
- **Profil** — Quote, Serie, Verteilung deiner Versuche.
- **Offline** — nach dem ersten Besuch auch ohne Netz; auf dem Handy über
  „Zum Startbildschirm hinzufügen" wie eine App.

**Ein Spiel von UPCrew.** Du spielst mit deinem UPCrew-Konto — einem Konto
für alle Spiele von UPCrew, mit denselben Freunden überall.

## Datenschutz

- Gespeichert werden dein Spitzname, eine Prüfsumme deines Passworts (nie das
  Passwort selbst), deine Freundesliste und deine Ergebnisse (Anzahl Versuche
  und das Farbmuster, nicht die Wörter).
- Die Datenbank ist die Firebase Realtime Database von UPCrew in Europa
  (Belgien). Sie
  ist für jeden mit der App lesbar — **trag nur einen Spitznamen ein, nichts
  Vertrauliches**, und benutze ein Passwort, das du nirgends sonst verwendest.
- Keine Werbung, keine Zähler, keine Cookies von Dritten.

## Wunsch oder Fehler?

Im Profil unter „Über Typoluck" auf **Wunsch oder Fehler melden** tippen.

## Technik

Reines HTML, CSS und JavaScript, keine Bibliothek, kein Bauschritt. Die
Datenbank wird über ihre REST-Schnittstelle angesprochen.
